# Tambayan Web Application

This is the web application for **Tambayan** (Campus Community Social Network), engineered with React 19, Vite, TypeScript, and Firebase Realtime Firestore & Authentication.

## Core Rules & Architecture

1. **Web App Framework**: React 19 + Vite.
2. **Design & Styling**: Pure Vanilla CSS design system with Terracotta Coral (`#FC7847`) and Teal accents. Avoid Tailwind unless explicitly requested.
3. **Images**: 100% lightweight `.webp` images stored in `public/images/`.
4. **Data & Auth**: 100% live real-time Firebase Auth and Firestore. Never use dummy or mock account data.
5. **Commands**:
   - `npm run dev`: Run local Vite dev server on port 3000.
   - `npx tsc --noEmit`: Typecheck TypeScript files.
   - `npm run build`: Production bundle verification.
